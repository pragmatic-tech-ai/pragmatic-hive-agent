# pragmatic-hive-agent architecture

| File | Role |
|---|---|
| `src/bin/pragmatic-agentd.ts` | The entry: `AgentCommand.Run(argv)`. |
| `src/agent-command.ts` | `AgentCommand`: no argument runs the rollout agent; `preflight` runs the engine install's checks and exits 0/1. |
| `src/agent-main.ts` | `AgentMain`: reads the environment, waits idle while not enrolled (`AgentEnrolment`), wires the agent and runs the poll loop (doubling backoff on failed ticks, capped). |
| `src/agent-enrolment.ts` | `AgentEnrolment`: whether a push-installed hive holds its channel token; without one it waits ready and idle, re-reading the token file each poll. |
| `src/enrolment/`, `src/identity/`, `src/internal-api/`, `src/kube/` | The connected (chart-installed) agent, C3.3: `ConnectedAgent` (when `ConnectedSettings.IsConnected`: the chart sets the pinned trust root file); `HiveIdentity` (the hive's Ed25519 key in Secret `pragmatic-hive-identity`, created once, never logged); `EnrolmentState` (ConfigMap `pragmatic-hive-enrolment`); `HiveEnrolment` (self-signed request over `HttpAgentChannel`, `EnrolmentHandshake` with the pinned root, then stored; platform refusals mapped to `HiveEnrolmentRefusal`); `AgentInternalApi` on 7210 (`POST /internal/enrol`, `GET /internal/enrolment`) behind `ConsoleCallerCheck` (TokenReview: audience `pragmatic-hive-agent`, the console's service account); `HiveReporter` (a signed `HiveReport` every poll: the agent, console, sign-in service and Postgres workloads, the environments); `InClusterHiveKube` (Secrets, ConfigMaps, TokenReviews, workload readiness). |
| `src/intents/` | Pull-only management (C3.4), Enrolled and Delegated hives only (a Hosted engine runs none): `IntentLoop` composes it; `IntentPuller` (each poll: pull after the cursor, verify batch and items under `PlatformTrust`, keep in `IntentStore` (ConfigMap `pragmatic-hive-intents`, about 1 MiB, oldest settled pruned), `IntentAdmissionDecider` (stricter level), waiting intents expire, due ones applied with a recheck, the agent's own upgrade last and reported first; the console's decision by digest signed by `ApprovalSigner` and sent, an approval applied at once); `IntentExecutor` and `handlers/` (`ComponentAtVersionHandler`: the named engine workload's image to the release repository at the digest, put back when it never readies; `RotateHandler`: trust root kept with its proving intent (`EnrolmentState` chain), hive key via `HiveSigning.Rotate` (swap only after the acknowledgement; `HiveKeyRecovery` at start), ingress certificate forwarded; `RepairHandler`: rollout restart; `EnvironmentIntentForwarder`: the console's `POST /internal/environment-intents` on 7211 with the projected token for `pragmatic-tenant-admin`, unreachable or busy = tried again next tick). The intent routes of `AgentInternalApi` (`GET /internal/intents`, `POST /internal/intents/<id>/decision`). One pod applies at a time (`IntentLease`, Lease `pragmatic-hive-agent-intents`, released on SIGTERM); the store merges concurrent writers on a conflict; an intent applies only in Delegated mode or with its stored approval verifying under the hive key for its digest; rolls are judged by `kubectl rollout status`'s rule (`KubeWorkload.RolledOut`). |
| `src/preflight/` | The engine chart's preflight hook (`pragmatic-agentd preflight`, C3.2): `Preflight` runs every `IPreflightCheck` (`cluster-version` ≥ 1.30, `storage-class`, `ingress-class`, `dns-name` (console, sign-in service, the environments' wildcard), `tls`, `engine-identity` (a kept engine keeps its ids), `workload-identity-issuer` (azure or aws realm secrets: the cluster's service-account issuer is publicly fetchable, 2.5)) even after a failure; `PreflightSettings` reads the chart's `PRAGMATIC_PREFLIGHT_*`; `PreflightCli` prints one line per check with its fix and exits 1 on any Fail. |
| `src/rollout-agent.ts` | `RolloutAgent.Tick`: fetch the target, list the environments, patch the obsolete ones, report the snapshot. |
| `src/agent-wiring.ts` | `AgentWiring`: the channel URLs, the label selector, deployment to environment state. |
| `src/k8s-api.ts` | `InClusterK8sApi`: lists and patches deployments through `pragmatic-kube`'s `KubeHttpsTransport` (service account). |
| `src/bounded-fetch.ts` | `BoundedFetch`: a fetch and its body read under one timeout. |
| `src/hive-agent-component.ts` | `HiveAgentComponent`: the component descriptor (no port, no storage). |
| `src/release-components.ts` | `Components`: the descriptor source the image build reads (`pragmatic-component-descriptors --components dist/release-components.js`). |
| `closure.json` | What the image copies; `pragmatic-closure-check` keeps it, the Dockerfile and the code in step. |

Tests: `src/tests` (the agent, its wiring, the Kubernetes calls, the bounded fetch, the descriptor golden and its
readers), `tests/` (the release module's descriptor equals the pragmatic-server golden digest; no TODL, Mural or
todl-runtime dependency).
